# Gerador de QR-Code

Projeto desenvolvido em **HTML, CSS e JavaScript** para gerar QR-Codes de forma simples e prática.  
Este projeto foi criado a partir de uma vídeo aula do curso **Hora de Codar**, que comprei para aprender JavaScript.  
Com este curso aprendi muito a criar meus projetos e conquistei um **certificado de HTML, CSS e JavaScript básico**.

## Funcionalidades
  - Geração de QR-Codes a partir de textos ou links.
  - Interface simples e intuitiva.
  - Exibição do QR-Code diretamente na tela.

## Estrutura do projeto

Gerador-QRCode/ 
├── index.html   # Página principal 
├── style.css    # Estilos da interface 
└── script.js    # Lógica de geração do QR-Code


## Como rodar
1. Clone este repositório:
   ```bash
   git clone https://github.com/j4yh4ck3r/Gerador-QRCode.git

   ```

Digite um texto ou link e clique em Gerar QR-Code.
